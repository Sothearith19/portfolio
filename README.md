# Portfolio - Sothearith Horn

My personal portfolio: a minimalist one-page site with an about section, projects, experience, tech stack, and contact info. Responsive on all modern devices.

**Live Site:** [portfolio-sothearithhorn.vercel.app](https://portfolio-sothearithhorn.vercel.app)

## Built with
Vanilla HTML5, CSS3 and JavaScript, with no framework or build step.

## Sections
- **About:** intro, links, light/dark theme toggle
- **Projects:** featured work with links, plus a GitHub contribution calendar
- **Experience:** background/timeline
- **Tech Stack:** tools and languages I work with
- **Contact:** how to reach me

## Editing
- Text content lives in `index.html`.
- The email copied by the Email buttons is set at the top of `static/js/copy.js`.
- Images go in `static/images/`, and a resume PDF goes in `static/resume/resume.pdf`.

## Deployment
Hosted on [Vercel](https://vercel.com). Every push to `main` redeploys automatically.
